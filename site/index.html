Point it at your running app. It walks your real user flows in a real browser and tells you what is actually broken, with proof. No API key.

View on GitHub See a sample report npm: sniff-qa

Try it in one command

npx sniff-qa --url http://localhost:3000

One command, no config, no API key, no Playwright setup. It also auto-detects a dev server on common ports.

Install into your AI CLI

One line links the Sniff skills into your CLI's skills directory. The MCP server is the universal fallback.

curl -fsSL https://raw.githubusercontent.com/Aboudjem/sniff/main/install.sh | bash -s codex
claude mcp add sniff-qa npx -- -y sniff-qa --mcp

What it finds

Broken pages and links

4xx/5xx, blank renders, dead internal and external links.

Console and network errors

Uncaught exceptions and failed requests during interaction.

Empty and fake data

Missing data, plus placeholders like lorem ipsum and TODO.

Broken forms and state-loss

Dead submit buttons, validation that never fires, wiped fields.

Loading and error states

Infinite spinners and missing error states.

Accessibility and responsive

axe-core checks plus a 375px mobile pass.

Proof, not noise

Measured on a fixture app planted with 21 bugs across all 12 classes: 21 of 21 found, 100% precision, zero false positives, zero findings on the clean control page. Those numbers are locked as a regression test in a suite of 507 tests. Every finding ships with the exact route, ordered steps, a screenshot, and the console or network excerpt that caught it.
